Admin · Data siswa

1. Lengkapi data siswa per kelas

Unduh roster kelas yang sudah ada agar nama dan NIS tidak perlu diketik ulang. File ini juga dapat dipakai untuk melengkapi data orang tua.

  1. Buka Kelas & Siswa, lalu pilih kelas.
  2. Klik Unduh data kelas (.xlsx). File data-kelas-[nama-kelas].xlsx berisi data yang sudah tersimpan. Jika kelas masih kosong, hanya ada judul kolom.
  3. Lengkapi kolom yang diperlukan. Jangan ubah atau hapus kolom ID Siswa SIGAP pada baris siswa lama.
  4. Tambahkan siswa baru pada baris berikutnya. Biarkan ID SIGAP kosong; isi NIS dan nama siswa.
  5. Kembali ke SIGAP, klik Impor daftar siswa, pilih file yang telah diisi, lalu klik Impor siswa.

Admin · Format e-Rapor

2. Simpan template sekolah

Satu template disimpan untuk satu kombinasi kelas, mapel, dan semester. File kosong boleh digunakan untuk menyimpan format; nilai yang sudah terisi juga akan masuk ke SIGAP.

  1. Buka Penilaian > Pengaturan e-Rapor.
  2. Pilih kelas, mata pelajaran, dan Semester I atau II yang sama dengan file sumber e-Rapor.
  3. Unggah file .xls asli dari e-Rapor SMP 2025.2 atau .xlsx yang benar-benar disimpan ulang melalui Excel. Ukuran maksimal 2 MB.
  4. Klik Periksa dan unggah. Periksa pesan hasil validasi.
  5. Jika pratinjau menampilkan siswa baru, verifikasi nama dan isi NIS asli untuk setiap siswa. Klik Buat siswa dan simpan.

Struktur yang perlu dipertahankan

Identitas dan roster

  • Header mapel_id
  • Header id_anggota_rombel
  • Header status kunci
  • Daftar siswa dan ID rombel dari file sekolah

Kolom nilai

  • Satu atau lebih kolom Sumatif
  • Kolom Akhir Semester Non Tes
  • Kolom Akhir Semester Tes
  • Urutan header dan kolom nilai asli
Jangan lakukanJangan menamai file lain dengan ekstensi .xls atau .xlsx saja. File .xlsx harus menjadi workbook Excel yang sebenarnya dan header e-Rapor perlu dipertahankan.
Pencocokan siswaSIGAP memakai pemetaan ID anggota rombel atau nama unik. NIS wajib untuk siswa baru dan harus benar-benar NIS sekolah. Siswa baru yang dibuat dari e-Rapor tidak otomatis memiliki akun orang tua.

NPSN pada file harus cocok dengan Profil Sekolah SIGAP jika NPSN sudah diisi. Siswa yang ada di roster SIGAP tetapi tidak ada di file perlu diperiksa sebelum impor.

Admin dan guru · Pemetaan nilai

3. Tentukan sumber setiap kolom

Pemetaan menentukan kolom e-Rapor mana yang mengikuti komponen nilai rutin SIGAP. Admin mengatur default dan izin; guru dapat mengatur pemetaan khusus bila diizinkan.

Pilihan pada SIGAPArti bagi guru
Jenis nilai SIGAP, misalnya Sumatif 1Kolom e-Rapor mengambil nilai dari komponen itu. Guru mengisi di halaman Nilai Siswa, lalu nilainya muncul di e-Rapor.
Isi langsung di halaman e-RaporTidak terhubung ke komponen nilai rutin. Guru mengisi kolom tersebut di tabel e-Rapor.

Contoh

Kolom pada templateSumber yang dipilihGuru mengisi di
Sumatif 1Sumatif 1Nilai Siswa SIGAP

Kolom catatan khususIsi langsung di halaman e-RaporTabel e-Rapor
  1. Admin buka Pengaturan e-Rapor dan atur sakelar Akses pemetaan e-Rapor untuk guru. Akses aktif secara default; bila dimatikan, hanya admin yang dapat mengubah pemetaan.
  2. Untuk setiap kolom pada bagian Sumber setiap kolom e-Rapor, pilih komponen nilai yang sesuai atau pilih isi langsung.
  3. Gunakan jenis nilai yang berbeda bila Semester I dan II mewakili nilai yang berbeda.
  4. Guru menyimpan pemetaan hanya untuk kelas/mapel/semester yang sedang dibuka. Admin dapat memilih cakupan default, lalu klik satu tombol Simpan pemetaan.
Urutan aturanDefault berlaku pada template lain di tahun ajaran dan semester yang sama jika kolomnya belum memiliki pemetaan khusus. Default khusus mapel mengalahkan default semua mapel; pemetaan khusus template tetap diutamakan. Perubahan tercatat pada riwayat bersama nama pelaku dan waktu.
HasilnyaGuru memasukkan nilai yang dipetakan sekali di halaman Nilai Siswa. Kolom e-Rapor yang memakai sumber SIGAP akan tampil dari nilai itu dan terkunci untuk edit langsung.
Saat mengubah pemetaanNilai lama tetap tersimpan pada komponen sebelumnya. Periksa sumber lama dan baru. Nilai langsung yang sudah ada dapat disalin ke sumber baru jika sumber itu masih kosong.

Nama dan pilihan komponen nilai dikelola pada menu Tahun Ajaran. Pastikan komponen yang diperlukan sudah tersedia sebelum menetapkan sumbernya.

Guru · Isi dan ekspor

4. Isi nilai lalu unduh file

A. Nilai rutin SIGAP

  1. Buka Penilaian > Nilai Siswa.
  2. Pilih kelas, mapel, dan jenis nilai.
  3. Klik Lihat Rekap, isi nilai, lalu klik Simpan Semua Perubahan.

B. Nilai resmi e-Rapor

  1. Klik Impor / Ekspor e-Rapor.
  2. Pilih kelas, mapel, dan semester.
  3. Klik Tampilkan nilai.

Lengkapi nilai e-Rapor

  1. Jika template belum disimpan, unggah file sumber dari e-Rapor sesuai akses. Hanya admin yang dapat membuat siswa dari pratinjau roster.
  2. Kolom yang dipetakan akan menampilkan nilai SIGAP. Kolom dengan pilihan Isi langsung di halaman e-Rapor dapat diedit pada tabel.
  3. Isi atau koreksi nilai langsung, lalu klik Simpan nilai. Nilai harus berupa angka 0 sampai 100. Mengosongkan nilai langsung lalu menyimpan akan menghapus nilai tersebut.
  4. Setelah semua siswa cocok, unduh .xls (format sekolah) atau .xlsx. Tombol ekspor tampil jika template tersedia dan pemetaan roster lengkap.
  5. Buka file unduhan dan periksa kelas, mapel, semester, siswa, serta nilainya. Lalu unggah file tersebut ke e-Rapor sekolah.

5. Periksa masalah umum

Pesan atau kondisiTindakan

Kelas atau mapel tidak cocokSamakan pilihan kelas, tingkat, mapel, dan semester dengan file e-Rapor.

Sebelum mengirim file ke e-Rapor

  • Kelas, mapel, semester, dan NPSN cocok.
  • Daftar siswa dan ID anggota rombel sudah cocok.
  • Nilai yang dipetakan dan nilai langsung sudah diperiksa.
  • Perubahan nilai langsung sudah disimpan.
  • File ekspor dibuka dan diperiksa sebelum diunggah.
Agar orang tua dapat melihat nilaiAdmin buka Periode Akademik dan klik Publikasikan Nilai. Nilai resmi e-Rapor tampil terpisah dari nilai harian SIGAP jika template dan nilainya tersedia.
